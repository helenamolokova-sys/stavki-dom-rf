# stavki-dom-rf

Файл `rates.json` — рыночная вилка ставок по ипотеке для квизов на dostupnayaipoteka.ru
(ипотека, рефинансирование, новостройки). Квизы читают его по адресу
`https://raw.githubusercontent.com/helenamolokova-sys/stavki-dom-rf/main/rates.json`;
не открылся или не прошёл проверку — берут запасные ставки, вшитые в блок.

- Обновляет `.github/workflows/obnovit.yml` (скрипт `.github/obnovit.py`): среда, повторы в четверг и пятницу.
  Облачная рутина Claude не годится — её песочница не пускает на спроси.дом.рф.
- Любое сомнение (не разобрал статью, скачок больше 3 п.п., нет обзора к четвергу) → `rates.json` не трогается,
  пишется `trevoga.txt`, отчёт уходит в Telegram. Списка банков в тексте нет → нижняя прежняя, верхняя новая, пометка в отчёте.
- Проверка разбора без записи: `python3 .github/obnovit.py --proverka статья.html`; подмена даты — `SEGODNYA=ГГГГ-ММ-ДД`.
- Источник — «Обзор ставок по ипотеке в банках» СПРОСИ.ДОМ.РФ: нижняя — лучшая среди крупных
  банков, верхняя — средневзвешенная по вторичке.
- Отчёт и тревоги — `.github/workflows/otchet.yml` → бот @Stavkimolokiva_bot, тема 1206.
- `istoriya/` — копия каждой недели с банком и ссылкой на статью.
